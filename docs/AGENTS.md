# AGENTS.md

## Objetivo

Este projeto utiliza React + TypeScript + CSS Modules.

Ao implementar novas funcionalidades:

- Reutilizar componentes existentes sempre que possível.
- Não criar código duplicado.
- Utilizar tipagem forte.
- Não utilizar any.
- Preferir componentes funcionais.
- Seguir a estrutura de pastas existente.

## Frontend

Tecnologias permitidas:

- React
- TypeScript
- CSS Modules
- React Router

Tecnologias proibidas:

- jQuery
- Bootstrap
- Tailwind
- Styled Components

## Estrutura

Componentes:
- pequenos
- reutilizáveis
- focados em uma responsabilidade

CSS:
- NomeComponente.module.css
- evitar CSS global

## Qualidade

Antes de finalizar:

- verificar erros TypeScript
- remover código morto
- validar responsividade
- reutilizar hooks existentes

## Regra importante

Sempre analisar primeiro os componentes existentes antes de criar novos componentes.
